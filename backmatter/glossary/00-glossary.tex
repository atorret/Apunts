This glossary has three parts. \emph{Part A} lists the symbols, grouped by kind, with the place where each is introduced.
\emph{Part B} lists the terms alphabetically, each with a one-line definition and a pointer to the text; synonyms are given as
``see'' entries. \emph{Part C} collects the identities used throughout, numbered C.1, C.2, \dots, each with a complete proof in the
step-by-step style of the text. Where a proof was only sketched (or omitted) in the body, the proof here is new and says so.
