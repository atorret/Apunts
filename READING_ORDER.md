Read the books from left to right. An arrow runs from a book you finish first to the book that waits for it. Books in the same column do not depend on each other, so they can be read in either order. A book with no arrow pointing to it is a place to start.

Inside a book, follow that book's organization file. Chapters are listed in reading order, and each row names what must come first. An optional prerequisite is marked (opt.). What to explain has one section for each chapter, saying what that chapter must teach. The same order for every book is collected in [EDITORIAL_ORGANIZATION.md](EDITORIAL_ORGANIZATION.md).
