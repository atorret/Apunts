Library

Editorial status is saved from the library view or the records table. Import a book organization file, or a chapter-changes file that names the new, edited, and deleted books and chapters. Either import rewrites the editorial organization.

Library

Books follow series order, left to right, three to a row. Click a book. Hard prerequisites are outlined. Prerequisites of those are blue. Optional ones are dashed.

Reading order

Click a book. Boxes run left to right. Each box lists the chapters that book has to supply. “All chapters” means the whole book.

Selection

Click a book or a chapter. Book status and target level apply to every chapter. A chapter row changes only that chapter.

Records

Every book, part, chapter, concept, and roadmap is listed. Change presence, status, or level on a book or chapter to save. Editing a book applies the same values to every chapter in that book (book level is the target level). Retired chapters have no workflow status.

Export

Download overwrites the file of the same name in the project. Editorial organization is the current syllabus. Internal references are written to INTERNAL_REFERENCES.md. Reading order is written to READING_ORDER.md and lists which books must be finished first. External sources are written to EXTERNAL_SOURCES.md. A book organization file is written into that book's folder and includes its sources, which books must be finished first, and what each chapter must teach. All books overwrites the organization file in every book folder.
